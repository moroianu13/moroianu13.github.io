What I built

The application accepts age, sex, BMI, number of children, smoker status and region. It converts those values into the representation expected by the trained model and returns an estimated insurance charge through a Streamlit interface.

Beyond a single prediction

The app also keeps prediction history during the session, exposes the strongest model coefficients as a feature-impact chart and supports batch prediction from uploaded CSV files with downloadable results.

Manual input or CSV→Preprocessing→Polynomial features→Regression model→Prediction + analysis

What it demonstrates

This project shows an early move toward end-to-end ML product thinking: model persistence, interactive inference, lightweight explainability, session state, batch processing and export rather than a notebook-only result.
