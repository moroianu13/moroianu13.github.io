Insurance Cost Predictor

A regression project predicting insurance charges through a Streamlit application.

← ProjectsGitHubLive demo

In short

An early end-to-end ML app using feature engineering, regression and a web interface.

Stack / themes

PythonScikit-learnPandasStreamlitRegression

Workflow

The app uses age, BMI, smoker status, children, sex and region as inputs, with preprocessing and regression packaged into an interactive Streamlit workflow.

What it demonstrates

This project reinforced the pattern of turning a model into a usable application rather than stopping at evaluation metrics.
