Face Recognition Webcam App

A local desktop app for real-time face enrollment and recognition.

← ProjectsGitHub

In short

A computer-vision project using local inference and local embedding storage rather than a cloud recognition service.

Stack / themes

PythonOpenCVInsightFaceNumPyONNX Runtime

The original project page includes a local demo video.

How it works

The enrollment flow detects a visible face and stores its embedding locally. The recognition flow compares live embeddings with the saved vectors using cosine similarity.

Privacy

Known-face embeddings are stored locally and excluded from the public repository.
