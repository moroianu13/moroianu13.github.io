Face Recognition Webcam App

Real-time face enrollment and recognition with Python, OpenCV, and InsightFace

Prepared by: Adrian Moroianu | Updated: April 2026

Overview

This project is a local desktop face recognition app that uses a webcam to enroll known faces and recognize them in real time. It combines OpenCV for camera access and display, InsightFace for face detection and embeddings, and NumPy for similarity matching.

The app stores face embeddings locally in the known_faces folder. These personal files are intentionally excluded from GitHub.

Demo

How It Works

  • The enrollment script opens the webcam and detects the largest visible face.
  • When a key is pressed, the app saves that face as a numerical embedding.
  • The recognition script compares each live face embedding with saved embeddings.
  • If cosine similarity passes the threshold, the app displays the matched name and score.

Tech Stack

  • Python for the application logic
  • OpenCV for webcam capture, drawing, and display
  • InsightFace for face detection and embedding extraction
  • NumPy for vector comparison and embedding storage
  • ONNX Runtime for running the face model locally on CPU
  • PyInstaller support for creating a desktop executable

Key Features

  • Live webcam face detection and recognition
  • Local enrollment workflow for known identities
  • Configurable webcam index through an environment variable
  • Privacy-conscious local storage for face embeddings
