System design

Conversation, memory, inference and execution are deliberately separated.

Red Queen is built around a local-agent architecture rather than giving a language model unrestricted control of the machine. Letta manages conversational memory, Qwen runs locally through Ollama, and the Tool Controller owns execution policy.

User→Red Queen→Letta→Qwen / Ollama→Tool Controller→Approved tools
What I builtThe local agent runtime, desktop/control architecture, tool boundary model, persistent-memory integration and a state-aware UI that makes agent behavior inspectable.

Security by design

The controller is the final authority.

Protected operations require scoped approval, generic shell/admin access is not exposed, and screen vision is isolated from direct action execution. This is a core architectural decision, not a UI label.
