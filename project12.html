Overview

Regional healthcare pressure, made inspectable.

The dashboard combines public NRW and Ruhr hospital statistics, hospital registry classification, demographic indicators, unemployment indicators and scenario-based forecasts into a reproducible local analysis workflow.

The project uses public city-level aggregate data and hospital-site registry records. It does not contain patient-level records.
