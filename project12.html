Hospital Pressure Index — Ruhrgebiet

A local dashboard for comparing city-level hospital pressure across the Ruhrgebiet.

← ProjectsGitHub

In short

A healthcare analytics project combining public hospital, demographic and socio-economic data into transparent city-level pressure layers and forecast scenarios.

Stack / themes

PythonPandasNumPyStreamlitPlotlyPyDeckStatsmodelsPytest

Uses public aggregate and registry data; no patient-level records.

Data workflow

The project downloads and cleans public NRW and hospital-registry data, classifies hospital records, merges multiple pressure drivers and prepares historical and forecast-ready layers.

Dashboard

The UI provides a regional overview, city deep dives, map-based patterns, pressure-driver views and scenario comparisons.
