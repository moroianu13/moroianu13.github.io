Hospital Pressure Index - Ruhrgebiet

Local Streamlit dashboard for city-level hospital pressure analysis across the Ruhrgebiet

Prepared by: Adrian Moroianu | Updated: June 2026

Overview

Hospital Pressure Index - Ruhrgebiet builds a reproducible local analysis workflow for comparing hospital-system pressure across Ruhrgebiet cities. It combines public NRW and Ruhr hospital statistics, hospital registry classification, demographic indicators, unemployment indicators, and scenario-based forecasts into one Streamlit dashboard.

The dashboard supports both regional overview and city deep-dive views, helping compare average regional pressure, highest and lowest pressure cities, map-based city patterns, layer changes, and forecast scenarios.

This project uses public city-level aggregate data and hospital-site registry records. It does not contain patient-level records, credentials, paid API keys, or cloud-only services.

Region overview showing the Ruhr city pressure map, KPI cards, and selected analysis layer.

What It Answers

  • Which Ruhrgebiet cities show the highest and lowest hospital pressure in the selected layer?
  • How does pressure change when comparing all hospitals, acute hospitals, and demographic pressure layers?
  • Which local drivers contribute most to a selected city's pressure score?
  • How do forecast scenarios change the expected Hospital Pressure Index over time?

Dashboard Views

  • Region overview with KPI cards, city pressure map, timeline, and city ranking.
  • City deep dive with selected-city metrics, pressure drivers, trends, and layer comparison.
  • Forecast mode with scenario comparison for available forecast layers.

Data Pipeline

  • Download and clean public NRW demographics, unemployment, hospital capacity, and hospital registry data.
  • Classify hospital registry records and apply a manual review file for acute-care relevance.
  • Merge hospital, demographic, and socio-economic indicators into adjusted city-level pressure datasets.
  • Build historical and forecast-ready HPI layers for Streamlit dashboard consumption.
  • Test core pressure-index logic with a focused Pytest suite.

Tech Stack

  • Python for data acquisition, cleaning, modeling, and dashboard logic
  • Pandas and NumPy for structured data processing
  • Streamlit for the local interactive dashboard
  • Plotly and PyDeck for charts and map views
  • Scikit-learn and Statsmodels for analytical and forecast support
  • Pytest for validating the pressure-index calculation behavior

Project Scope

The app is designed as a local research and analysis dashboard, not as a production-secured public healthcare system. Its value is in reproducible data preparation, transparent assumptions, manual review traceability, and a dashboard that makes the resulting pressure layers easier to inspect.
