What I built

The project starts with a cleaned vehicle dataset and a trained regression model, then exposes prediction through Streamlit. The original application accepts four model features — curb weight, engine size, horsepower and vehicle width — and returns a price estimate.

Workflow

Clean data→Select features→Train regression model→Save model→Streamlit prediction UI

This was one of the first projects where I treated deployment and user interaction as part of the ML workflow rather than ending with a notebook.

What it demonstrates

It shows the transition from exploratory ML work to packaging a model into a simple application: loading a persisted model, validating user inputs, constructing the model feature frame and returning a readable prediction result.
